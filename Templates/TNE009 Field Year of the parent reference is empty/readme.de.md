# Feld "Jahr" des übergeordneten Titels ist leer

Diese programmierte Bedingung prüft, ob das Feld "Jahr" und das aufgelöste Jahr ("YearResolved") des übergeordneten Titels leer sind.

## Voraussetzungen
Citavi 6 (oder höher)

## Beispiele
Sie zitieren einen Beitrag in einem Tagungsband oder Sammelwerk. Das Jahr wird dabei vom übergeordneten Titel geerbt ("Year derived"). Wenn der übergeordnete Titel kein Jahr enthält, soll statt einer leeren Ausgabe ein Platzhalter erscheinen – z. B. verlangt der IEEE Reference Guide in diesem Fall "(n.d.)":

- P. Contribution, "Contribution of the Proceeding," in Proceeding: Main, A. Elias, Ed., (n.d.).

Duplizieren Sie dazu das Template des Dokumententyps, weisen Sie dem Duplikat diese Bedingung zu und ersetzen Sie im Duplikat den Baustein "Year derived" durch ein statisches Textelement mit dem Inhalt "(n.d.)".

## Installation
Siehe Citavi Handbuch: [Creating Custom Templates](http://www.citavi.com/creating_custom_templates)
